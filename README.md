### @AI_DVD6：儿童科普漫剧量产

**核心提炼**
- 约束优先：2 人物 1 场景；开头 3 秒必冲突、结尾必反转；每镜 10 秒、一镜最多 2 个动作
- 台词镜头避正脸：捂嘴/背身/只拍手，配音后期加——绕开 AI 口型崩坏
- 定妆照是"身份锚"：2 人物+1 场景各一张，每镜必传，否则外形跑偏
- 提示词末尾加外形强调句+"只生成一次，不合格先给我看，不要自动重试"，防后台烧额度（7 次生成仅用约 3.5% 额度）
- 每镜截第 1/5/9 秒三帧发 Claude 质检：通过 / 剪辑里修 / 必须重做
- 省钱决策表：偏色用剪映 HSL 调、穿帮放大裁掉或贴纸盖；只有"换脸"或知识画错才重做；知识卡用静帧大字图，还能盖住画错处

**适用场景**：想做垂类知识/科普账号、追求稳定量产的人。

**怎么用它搞钱**：复制模板换赛道（历史/健康/育儿），每天量产发小红书起号接广告带货。

### @BDFrankHoubre：AI 短片三幕式剧本指南

**核心提炼**
- 核心论点：AI 工具只生成单个镜头的画面，无法替你决定故事走向；先把故事写在纸上再生成
- 三幕式：第一幕确立角色与目标，第二幕设障碍不断加码，第三幕逼角色做决定；缺一个就是"氛围集锦"
- 四步搭建（生成镜头前）：一句话写清主角欲望与代价→第二幕只选一个障碍→先定转折点再写结局→最后拆镜头表
- 新手误区：工具生成电影感画面太容易，误以为"写作已经发生了"——漂亮镜头≠故事成立
- 顺序：三幕提纲→分镜→最后生成；事后修结构代价巨大
- 如实说明：带 ScreenWeaver 工具软推广；其他结构（五幕式、起承转结）也可用

**适用场景**：AI 短片画面已经不错、但故事立不住的新手。

**怎么用它搞钱**：用这套结构做短片样片接单，或沉淀成中文 AI 短片写作付费教程。

### @meAsifAi：AI 电影制作蓝图 Master Prompt V3

**核心提炼**
- 核心原则：先规划电影→建立视觉参考→生成故事板图像→审核通过再动画化→组装成片
- 人物一致性：先生成单人肖像锁定身份（Character Identity Lock），再做多视角参考表；同一角色不同造型另建状态参考，绝不静默重新设计
- 20 步全流程：项目输入→创意方向→角色清单→肖像→参考表→资产清单→场景参考→服装化妆连续性→分场→分镜头→故事板提示词→故事板审核→视频生成提示词（每镜少量清晰动作，注明起始/结束状态）→镜头衔接→配音计划→调色→剪辑→资产库→生产追踪表→新手指南
- 资产全用稳定 ID 编号（CHAR_01、SC01_SH001 等），每个提示词独立可用
- 用已审核故事板图做视频首帧，避开身份突变/道具消失/手脚变形等常见错误
